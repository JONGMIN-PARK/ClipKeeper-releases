# ClipKeeper 사용 설명서

복사한 **텍스트·이미지·파일을 모두 기억**해 두었다가, 단축키 한 번으로 찾아 붙여넣는 Windows 클립보드 히스토리 매니저입니다. 트레이에 상주하며 대기 중 CPU 사용은 0에 가깝습니다.

---

## 설치

1. [최신 릴리스](https://github.com/JONGMIN-PARK/ClipKeeper-releases/releases/latest)에서 **ClipKeeper.zip** 을 받아 압축을 풉니다.
2. **ClipKeeper.exe** 를 실행하면 설치 창이 뜹니다 → **설치**.
   - .NET 설치·관리자 권한이 필요 없습니다 (Windows 10/11 64비트, 런타임 포함).
   - 바탕화면·시작 메뉴 바로가기와 **Windows 시작 시 자동 실행**이 등록됩니다.
   - SmartScreen 경고가 보이면 **추가 정보 → 실행**.

![설치](screenshots/shot-installer.png)

처음 실행하면 간단한 시작 안내가 나옵니다.

![시작 안내](screenshots/shot-welcome.png)

제거: **설정 → 앱 → 설치된 앱 → ClipKeeper → 제거** (기록 유지/삭제를 고를 수 있습니다).

---

## 기본 사용

| 하고 싶은 것 | 방법 |
|---|---|
| 히스토리 열기 | `Ctrl+Shift+V` (설정에서 변경), 트레이 아이콘 클릭, 화면 상단 빨간 띠 클릭 |
| 찾기 | 열자마자 바로 입력 — 입력 즉시 검색 (공백은 AND) |
| 붙여넣기 | `Enter` 서식 그대로 · `Ctrl+Shift+Enter` 서식 없이 · `Shift+Enter` 복사만 · `Ctrl+1~9` 빠른 붙여넣기 · 더블클릭 |
| 상단 고정 | `Ctrl+P` / 우클릭. 목록 맨 위에 고정되고 자동 삭제에서 제외 |
| 변환하여 붙여넣기 | `Ctrl+T` — 공백·중복 정리, 대소문자, JSON 정렬/압축, 표·CSV·숫자 서식 등 |

![히스토리](screenshots/shot-history.png)

- **미리보기**: 오른쪽에 내용을 보여 주고, Excel 범위를 복사하면 표와 **열별 통계(합계·평균·중앙값·최소·최대·표준편차)** 를 함께 표시합니다.
- **빨간 띠**: 화면 맨 위에 마우스를 올리면 최근 기록·문구가 펼쳐집니다. 클릭하면 쓰던 창에 바로 붙여넣습니다(포커스를 뺏지 않음). 끌어서 옮길 수 있고, 트레이 메뉴에서 끌 수 있습니다.

## 이미지 속 글자 검색 (OCR)

복사한 **이미지 안의 글자**를 백그라운드에서 자동으로 추출해, 검색으로 이미지를 찾을 수 있습니다. 찾은 단어는 **이미지 위에 하이라이트**로 표시됩니다. 한국어·영어를 지원하며, 처음 사용할 때 인식 모델을 한 번 내려받습니다.

![OCR 검색 하이라이트](screenshots/shot-ocr.png)

- 이미지를 우클릭 → **🔤 글자 추출 (OCR)** 로 인식한 글자를 바로 복사할 수 있습니다.
- 설정에서 끌 수 있습니다. (Pro 기능)

## 문구집

자주 쓰는 문장을 폴더로 모아 두고 전역 단축키(`Ctrl+Alt+1~9`)로 바로 붙여넣습니다.

- **변수**: `{date} {time} {datetime} {weekday} {clipboard}` 등이 붙여넣을 때 실제 값으로 바뀝니다.
- **입력칸**: `{입력:이름}` / `{입력:이름=기본값}` 은 붙여넣을 때 물어봅니다 — 보고·안내문 템플릿에 유용합니다.
- 업무용 예시 문구(보고·조직 관리·개발)를 한 번에 추가할 수 있습니다. JSON 으로 가져오기/내보내기 지원.

## 인사이트 · 주간 리포트

복사·붙여넣기·문구 사용을 집계해 작업 패턴을 보여 줍니다(내용은 저장하지 않고 횟수·시각·프로그램 이름만, 1년 보관). 매주 월요일 지난주 리포트를 문서 폴더에 자동 생성하고, 메일·Word 에 표 서식으로 복사할 수 있습니다. (Pro 기능)

![인사이트](screenshots/shot-insights.png)

## 설정

모든 설정은 **바꾸는 즉시 저장·적용**됩니다.

![설정](screenshots/shot-settings.png)

- **보관·정리**: 보관 기간(1주~무기한), 휴지통 기간, 오래된 기록 정리.
- **민감 정보**: API 키·토큰·비밀번호·카드번호·주민등록번호를 감지해 목록에서 가리고, 정한 시간 뒤 자동 삭제합니다. 비밀번호 관리자의 '기록 제외' 표시를 존중하고, 제외할 프로그램을 지정할 수 있습니다.
- **백업/복원**: 기록·문구집·이미지를 zip 하나로 백업·복원.
- **자동 업데이트**: 새 버전을 자동으로 받아 쉬는 동안 설치합니다.
- **라이선스**: 이 PC 의 **머신 ID** 를 복사해 보내면 그 PC 용 키를 받습니다. PC 를 바꾸면 머신 ID 를 다시 보내 재발급받습니다.

## 안전 · 개인정보

모든 기록은 **이 PC 에만** 저장됩니다(`%LocalAppData%\ClipKeeper`). 인터넷으로 보내지 않습니다. 저장소가 손상되면 자동 백업(하루 1회 스냅샷)으로 복구하거나, 읽을 수 있는 기록을 새 저장소로 옮깁니다.

문제가 있으면 **설정 → ℹ 정보 → 진단 정보 내보내기** 파일(클립보드 내용은 포함하지 않음)을 보내 주세요.

## 라이선스 (Pro)

배포본은 **7일 체험판**입니다. 체험이 끝나도 기록은 계속 저장되고 기본 기능(최근 100개 보기·검색·붙여넣기·상단 고정·문구집)은 그대로 쓸 수 있습니다. Pro 기능(전체 기록, OCR, 변환, 인사이트·주간 리포트, 묶음·내보내기, 자료 수집, 빨간 띠, 문구 단축키)은 라이선스 키로 사용합니다. 라이선스는 한 PC 에서만 쓸 수 있습니다.
